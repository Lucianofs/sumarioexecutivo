## Regra profissional
O portfólio é amplo para descoberta. O currículo ATS deve ser adaptado para cada vaga importante, usando as palavras-chave reais da descrição da vaga e apenas experiências comprováveis.

## Internacional
Manter versão em inglês do CV ATS para oportunidades remotas internacionais. Não declarar fluência em inglês enquanto o nível real for básico.

## Conformidade
Saúde, terapias, políticas públicas e outras áreas reguladas devem ser apresentadas conforme formação, habilitação, credenciamento, contratação, protocolos e requisitos institucionais. Não prometer cura nem resultados clínicos sem evidência.
